# The house style

Ptome's PDF, HTML page, website and EPUB share one look by default
(ADR-0011). It starts from Asciidoctor's and asciidoctor-pdf's and
changes what the rules of typesetting ask for: Matthew Butterick's
*Practical Typography* (and *Typography for Lawyers*), Robert
Bringhurst's *The Elements of Typographic Style*, and, for code, notes and
figures, the conventions of technical publishers' books. The markup is
Asciidoctor's; only the PDF theme and the stylesheets change. The
values are the built-in look `ptome` (`data/looks/ptome-look.yml`,
`doc/looks.md`), which the PDF theme is compiled from.

The classic looks are one setting away: `asciidoctor-compat` (an
attribute, `PTOME_COMPAT`, or `compat:` in `ptome.yml`; ADR-0015
and `doc/books.md`), for every format or a list. Each format also has its
own: `-a stylesheet=asciidoctor` (HTML, website), `-a
epub3-stylesheet=asciidoctor-epub3` (EPUB), `-a pdf-theme=default` (PDF;
`-a pdf-compat` for asciidoctor-pdf's page rules too).

## Rules

What the values follow:

| Element | Rule |
| --- | --- |
| Text face | a serif with real italics and small capitals |
| Heading and label face | a sans, bold |
| Code face | a monospace, a little smaller than the text |
| Text size | 10–12 pt in print, 16–20 px on screen; an e-book's reader's |
| Line spacing | 120–145% in print, about 160% on screen |
| Measure | 45–90 characters, 60–75 best |
| Paragraphs | space between or a first-line indent, not both: space, as technical books do |
| Alignment | justified only with hyphenation |
| Headings | bold, near-black, a modest scale, more space above than below, kept with what follows |
| Color | for links and labels only; text not pure black on screen |
| Code blocks | a light tint, no border, room around |
| Notes and warnings | a label in the heading face, a rule beside the text |
| Tables | horizontal rules only, a heavier one under the header |
| Captions | smaller, in the heading face |
| Small capitals | from the font, never shrunk capitals |

Behaviors that are not values: `%unbreakable` keeps a block on one page
in the PDF and is `break-inside: avoid` in HTML's print and an EPUB;
footnotes are at the foot of the page in the PDF (the modern engine), at
the end of the page in HTML, pop-ups in an EPUB.

Generated text (caption numbers, footnote markers, callout markers) is
not part of the style: its defaults are Asciidoctor's (ADR-0010), and the
templates change it.
