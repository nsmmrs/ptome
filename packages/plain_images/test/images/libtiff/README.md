# libtiff's test images

The `.tif` and `.tiff` files of libtiff's `test/images` (each photometric,
bit depth and compression, fax, old-style JPEG and LZW, tiles, IFD loops),
from https://gitlab.com/libtiff/libtiff at commit
9dff73bebc5661f2dace6f16e14cf9e857172f4e, under libtiff's licence
(LICENSE.md). test/tiff_test.dart decodes each as libtiff's tiff2rgba does.
